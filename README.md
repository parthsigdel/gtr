## What Gtr is?
A terminal client for GitHub notifications, issues, PRs, and reviews — auth token stays local, nothing touches a server.

## Current features
-> List notifications, issues, PRs, and reviews

-> View detailed descriptions

-> Open selected notification, issues, pr, or review in your browser. 

-> Mark notification as read (straight from your terminal).

## Installation
### Requirements
Requires - [.NET 10.0 SDK](https://dotnet.microsoft.com/download) or later

```
git clone https://github.com/CoderParth/gtr.git
cd gtr
dotnet run
```
